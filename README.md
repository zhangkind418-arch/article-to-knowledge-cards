# make-knowledge-cards

一个面向 Codex 的 Skill：把用户粘贴的文章或本地 Markdown/TXT 文件整理成便于学习和复习的知识卡片。它帮助读者从长文中抓出重要知识点，同时避免重复、过度概括或补入原文没有的信息。

## 解决的问题

阅读文章后，重要概念常散落在不同段落，复习时不容易快速回忆。此 Skill 将文章中的关键内容拆成一张一知识点的卡片，并用简明解释以及原文例子或自测题帮助理解。

## 主要功能

- 从用户粘贴的文章或指定的本地 `.md`、`.markdown`、`.txt` 文件提取知识点。
- 通常生成 5～8 张卡片；如果原文可支持的独立知识点不足 5 个，就少生成，不为凑数编造内容。
- 优先保留重要概念、主张、机制、区别、步骤和具体经验；合并重复或重叠内容。
- 每张卡片包含标题、核心知识、简明解释，以及原文例子或有原文依据的自测问题。
- 保留原文的限定和不确定性，不添加外部事实或虚构例子。

目前不支持网页抓取、PDF、Anki 卡组生成或图形界面操作。

## 安装方法

1. 将本项目中的 `skills/make-knowledge-cards` 文件夹复制到 Codex 的个人 Skills 目录：
   - Windows 默认位置：`%USERPROFILE%\.codex\skills\make-knowledge-cards`
   - macOS/Linux 默认位置：`~/.codex/skills/make-knowledge-cards`
2. 如果你设置了 `CODEX_HOME`，将文件夹放进 `%CODEX_HOME%\skills\make-knowledge-cards`（Windows）或 `$CODEX_HOME/skills/make-knowledge-cards`（macOS/Linux）。
3. 确认 `SKILL.md` 与 `agents/openai.yaml` 位于上述文件夹中。若 Codex 尚未识别新 Skill，重新加载或重启 Codex。

本项目内的 Skill 源文件位于 `skills/make-knowledge-cards/`；将它复制到个人 Skills 目录后，即可在 Codex 中调用。

## 使用方法

- **粘贴文章：** 在 Codex 中输入 `$make-knowledge-cards`，并粘贴文章内容。
- **处理本地文件：** 输入 `$make-knowledge-cards`，提供本地 `.md`、`.markdown` 或 `.txt` 文件路径，并要求整理成知识卡片。
- 如果只找到少于 5 个有依据且互不重复的知识点，Skill 会生成更少的卡片并简要说明原因。

## 输入与输出示例

**输入：**

> 间隔复习是在多次学习之间留出时间间隔。与集中复习相比，在总学习时间相近时，分散练习通常更有利于长期记忆。复习间隔应结合材料难度和学习者的掌握程度调整。间隔太长时，学习者可能已经遗忘较多；间隔太短则可能失去分散练习的优势。

**输出：**

### 1. 间隔复习的基本做法
- **核心知识：** 在多次学习之间留出时间间隔。
- **简明解释：** 把学习分散到不同时间进行，而非集中在一次完成。
- **例子或自测：** 自测：间隔复习的关键安排是什么？

### 2. 分散练习与长期记忆
- **核心知识：** 总学习时间相近时，分散练习通常更有利于长期记忆。
- **简明解释：** 原文将分散练习与集中复习作比较，并指出前者通常更有利于长期记忆。
- **例子或自测：** 自测：在总学习时间相近时，哪种练习方式通常更有利于长期记忆？

### 3. 复习间隔需要因情况调整
- **核心知识：** 复习间隔应结合材料难度和学习者掌握程度调整。
- **简明解释：** 原文没有给出统一间隔，而是指出间隔安排要考虑材料和学习者的情况。
- **例子或自测：** 自测：调整复习间隔时，原文提到要考虑哪两方面？

### 4. 间隔过长的影响
- **核心知识：** 间隔太长时，学习者可能已经遗忘较多。
- **简明解释：** 间隔安排需要留意遗忘情况，过长可能降低复习效果。
- **例子或自测：** 自测：间隔太长时可能发生什么？

### 5. 间隔过短的影响
- **核心知识：** 间隔太短可能失去分散练习的优势。
- **简明解释：** 复习安排过于密集时，分散练习原本的好处可能无法体现。
- **例子或自测：** 自测：间隔太短可能失去什么？

上述输出仅使用输入文章中的信息；实际卡片数量根据原文内容决定。
